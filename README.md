# SceneGo

Windows용 SceneGo 공식 설치파일과 업데이트 배포 저장소입니다.

- 공식 웹사이트: https://scenego.bonnyemu32.chatgpt.site
- 사용법과 업데이트 도움말: https://scenego.bonnyemu32.chatgpt.site/guide.html
- 설치파일은 Releases에서 받을 수 있습니다.

SceneGo는 앱·문서·폴더·웹사이트를 작은 Scene으로 묶어 실행합니다. Scene은 파일로 직접 공유하며 개인 동작 학습은 각 PC에만 보관합니다.

업데이트가 연결된 설치본에서는 웹사이트를 열지 않고 앱 안에서 새 버전을 확인하고 다운로드할 수 있습니다. 업데이트 정보의 서명과 패키지 SHA-256을 검증합니다. 현재 Windows 설치파일에 대한 Authenticode 게시자 코드 서명은 없습니다.

문제 신고 시 비밀번호, 토큰, 개인 파일 경로, Discord/게임 계정 정보가 포함된 Scene이나 로그를 공개 게시하지 마세요.
